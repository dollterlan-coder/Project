# Project
## 项目一：AI新闻智能推送工作流
**技术栈**：N8N、LangChain、DeepSeek API、飞书机器人、飞书日历API、飞书Bitable
**功能**：每日早6点自动抓取AI新闻，结合飞书日程智能推荐阅读安排  
**量化成果**：每日节省20-30分钟，阅读效率提升70%，0人工干预

## 项目二：新闻自动采集与入库
**技术栈**：N8N、RSS协议、DeepSeek API、飞书Bitable
**功能**：并发采集4个RSS源，LLM自动摘要后入库飞书多维表格  
**量化成果**：信息获取效率提升90%，入库准确率95%+

## 项目三：电商客服留言智能分析机器人
**技术栈**：影刀RPA、Python、DeepSeek API、Excel自动化
**功能**：批量读取客户留言，AI情感分类（好评/中性/差评）后回写Excel  
**量化成果**：16条留言从10分钟压缩至30秒，准确率约90%
